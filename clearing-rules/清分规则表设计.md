## 1. 设计概览

清分规则按报文字段匹配目标系统。表名遵循 `[业务号]_CFG_XXX_XXX`，本文以 `CLR` 作为清分业务号。

| 表名 | 中文名称 | 表分类 | 建表方式 |
| --- | --- | --- | --- |
| `CLR_CFG_RULE_INFO` | 清分规则表 | 业务参数表 | 新建 |
| `CLR_CFG_RULE_CONDITION` | 清分规则条件表 | 业务参数表 | 新建 |
| `CLR_CFG_MESSAGE_FIELD` | 报文字段配置表 | 系统参数表 | 报文字段模型与其他系统复用 |
| `CLR_CFG_TARGET_SYSTEM` | 目标系统配置表 | 系统参数表 | 目标系统配置与其他系统复用 |

执行规则：每条规则对应一个目标系统和至少一个条件；条件按 AND 匹配；启用规则按优先级降序执行，首次命中即结束，全部未命中则标记为未清分。本期不支持版本、审批、嵌套条件和多目标分发。

## 2. 表关系

```text
CLR_CFG_RULE_INFO      1 ────────────────< N CLR_CFG_RULE_CONDITION
CLR_CFG_MESSAGE_FIELD  1 ── field_code ──< N CLR_CFG_RULE_CONDITION
CLR_CFG_RULE_INFO      N ── target_system_code ──▶ 1 CLR_CFG_TARGET_SYSTEM
```

## 3. 表定义

### 3.1. 清分规则表（CLR_CFG_RULE_INFO）

业务参数表，保存规则、适用报文、目标系统、优先级和启停状态。

| 字段名 | 类型 | 是否为空 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `rule_id` | BIGINT | 否 | 无 | 主键，规则唯一编号 |
| `rule_name` | VARCHAR(100) | 否 | 无 | 规则名称 |
| `message_type_code` | VARCHAR(32) | 否 | 无 | 适用的报文类型编码 |
| `target_system_code` | VARCHAR(32) | 否 | 无 | 目标系统编码 |
| `priority` | INT | 否 | `0` | 优先级，数值越大越先执行 |
| `enabled_flag` | CHAR(1) | 否 | `0` | 是否启用：`1`启用，`0`停用 |
| `description` | VARCHAR(500) | 是 | `NULL` | 规则说明 |
| `created_by` | VARCHAR(64) | 否 | 无 | 创建人 |
| `created_at` | TIMESTAMP | 否 | 无 | 创建时间 |
| `updated_by` | VARCHAR(64) | 否 | 无 | 最后修改人 |
| `updated_at` | TIMESTAMP | 否 | 无 | 最后修改时间 |

| 类型 | 字段 | 说明 |
| --- | --- | --- |
| 主键 | `rule_id` | 唯一标识规则 |
| 唯一约束 | `message_type_code, rule_name` | 同一报文类型下规则名称不可重复 |
| 普通索引 | `message_type_code, enabled_flag, priority` | 查询并排序启用规则 |

同一报文类型下，启用规则的优先级不得重复；目标系统必须有效且启用。规则只允许停用，不物理删除。

### 3.2. 清分规则条件表（CLR_CFG_RULE_CONDITION）

业务参数表，保存规则的 AND 匹配条件。

| 字段名 | 类型 | 是否为空 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `condition_id` | BIGINT | 否 | 无 | 主键，条件唯一编号 |
| `rule_id` | BIGINT | 否 | 无 | 所属清分规则编号 |
| `field_code` | VARCHAR(64) | 否 | 无 | 需要匹配的报文字段编码 |
| `operator_code` | VARCHAR(32) | 否 | 无 | 匹配操作符编码 |
| `compare_value` | TEXT | 是 | `NULL` | 比较值，建议保存为 JSON 值 |
| `created_by` | VARCHAR(64) | 否 | 无 | 创建人 |
| `created_at` | TIMESTAMP | 否 | 无 | 创建时间 |
| `updated_by` | VARCHAR(64) | 否 | 无 | 最后修改人 |
| `updated_at` | TIMESTAMP | 否 | 无 | 最后修改时间 |

| 类型 | 字段 | 说明 |
| --- | --- | --- |
| 主键 | `condition_id` | 唯一标识条件 |
| 外键或逻辑外键 | `rule_id` | 关联 `CLR_CFG_RULE_INFO.rule_id` |
| 普通索引 | `rule_id` | 查询规则条件 |

__匹配操作符__

操作符由后端枚举定义，并按字段类型返回前端。

| 操作符编码 | 含义 | 适用类型 |
| --- | --- | --- |
| `EQ` | 等于 | 全部 |
| `NE` | 不等于 | 全部 |
| `IN` | 属于集合 | 字符串、数字、日期 |
| `NOT_IN` | 不属于集合 | 字符串、数字、日期 |
| `CONTAINS` | 包含 | 字符串 |
| `NOT_CONTAINS` | 不包含 | 字符串 |
| `IS_EMPTY` | 为空 | 全部 |
| `IS_NOT_EMPTY` | 不为空 | 全部 |
| `GT` | 大于 | 数字、日期、日期时间 |
| `GE` | 大于等于 | 数字、日期、日期时间 |
| `LT` | 小于 | 数字、日期、日期时间 |
| `LE` | 小于等于 | 数字、日期、日期时间 |

__compare_value__

集合值使用 JSON 数组。`field_code` 必须有效且启用。

同一规则不得有重复条件。`IS_EMPTY`、`IS_NOT_EMPTY` 的 `compare_value` 必须 `NULL`，其他操作符必须有值；

| 操作符 | 保存值示例 |
| --- | --- |
| 等于字符串 | `"xxx"` |
| 大于数字 | `100` |
| 属于集合 | `["01", "02"]` |
| 为空 | `NULL` |

### 3.3. 报文字段配置表（CLR_CFG_MESSAGE_FIELD）

系统参数表，定义规则可选的报文字段；已有字段元数据时不重复建表。

| 字段名 | 类型 | 是否为空 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `field_id` | BIGINT | 否 | 无 | 主键，字段配置唯一编号 |
| `message_type_code` | VARCHAR(32) | 否 | 无 | 所属报文类型编码 |
| `field_code` | VARCHAR(64) | 否 | 无 | 字段编码 |
| `field_name` | VARCHAR(100) | 否 | 无 | 字段显示名称 |
| `field_path` | VARCHAR(256) | 否 | 无 | 解析后字段路径，例如 `body.A` |
| `data_type` | VARCHAR(20) | 否 | 无 | 数据类型 |
| `enabled_flag` | CHAR(1) | 否 | `1` | 是否允许用于规则配置 |
| `sort_no` | INT | 否 | `0` | 前端字段下拉框排序 |
| `description` | VARCHAR(500) | 是 | `NULL` | 字段说明 |
| `created_by` | VARCHAR(64) | 否 | 无 | 创建人 |
| `created_at` | TIMESTAMP | 否 | 无 | 创建时间 |
| `updated_by` | VARCHAR(64) | 否 | 无 | 最后修改人 |
| `updated_at` | TIMESTAMP | 否 | 无 | 最后修改时间 |

| 类型 | 字段 | 说明 |
| --- | --- | --- |
| 主键 | `field_id` | 唯一标识字段配置 |
| 唯一约束 | `message_type_code, field_code` | 同一报文类型下字段编码不可重复 |
| 普通索引 | `message_type_code, enabled_flag, sort_no` | 加载前端可选字段 |

`data_type` 支持 `STRING`、`NUMBER`、`DATE`、`DATETIME`、`BOOLEAN`。

### 3.4. 目标系统配置表（CLR_CFG_TARGET_SYSTEM）

系统参数表，提供可选清分目标；已有外围系统、渠道或应用配置时直接复用。

| 字段名 | 类型 | 是否为空 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `system_code` | VARCHAR(32) | 否 | 无 | 主键，目标系统编码 |
| `system_name` | VARCHAR(100) | 否 | 无 | 目标系统名称 |
| `enabled_flag` | CHAR(1) | 否 | `1` | 是否允许作为清分目标 |
| `description` | VARCHAR(500) | 是 | `NULL` | 系统说明 |
| `created_at` | TIMESTAMP | 否 | 无 | 创建时间 |
| `updated_at` | TIMESTAMP | 否 | 无 | 最后修改时间 |

该表不保存密码、密钥和连接地址，相关配置由投递模块管理。

## 4. 数据操作

- 列表以 `CLR_CFG_RULE_INFO` 为主表，按规则名称、报文类型、目标系统和启用状态查询，默认排序：

```sql
ORDER BY priority DESC, rule_id ASC
```

- 详情按 `rule_id` 分别查询规则和条件，条件按 `condition_id` 排序。
- 规则与条件在同一事务中保存；修改时替换该规则的条件数据。
- 条件摘要查询后拼装，不在规则表冗余保存。

规则执行：

```text
读取当前报文类型的启用规则
    ↓
按 priority 降序排列
    ↓
逐条判断规则的全部条件
    ↓
全部条件满足则命中
    ↓
返回 target_system_code 并停止匹配
    ↓
全部未命中则标记为未清分
```
