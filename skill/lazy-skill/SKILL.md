# 八条 Skill 铁律

1. **限定单一目标与边界。** 让 Skill 产出一个明确结果。写清处理什么、排除什么、允许读取或修改什么。
2. **保持单文件自包含。** 将必要规则、执行流程、输出格式和 Demo 全部写入一个 Markdown 文件。删除背景说明和外部引用。
3. **使用正向祈使句。** 使用“读取、搜索、修改、写入、验证”等精准动词。删除“可以、建议、一般来说、酌情处理”等表达。将禁止事项集中写入边界部分。
4. **编写顺序明确的原子 Step。** 每个 Step 只执行一个动作或产出一个结果。直接在 Step 中写清动作，删除括号和引用块中的补充解释。
5. **明确输入与输出。** 列出必需输入。后续 Step 依赖中间结果时，规定该中间结果的格式。给出最终输出的固定格式。
6. **提供完整成品 Demo。** 给出一个符合输出格式的真实成品。填写所有字段，不只提供空模板。
7. **给出判断与异常规则。** 使用可验证条件决定继续、重试、询问或停止。将未知信息标记为未知，禁止弱 AI 猜测。
8. **执行可验证的完成检查。** 使用检查框、固定 token、数量、文件路径或工具结果作为判据。删除“确保质量”等主观检查。
