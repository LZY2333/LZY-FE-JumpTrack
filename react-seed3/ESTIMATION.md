# CIES 账户变动申报系统 — 功能点估算表

> 口径：**1 功能点 = 0.5 人天**；一条 = 一个可完整跑通的功能（含前后端接口与表结构）
> 登录与用户权限通过 **OT4 接口**获取，不自建认证体系
> 前端工程化单独列于文末，不计入业务功能点
